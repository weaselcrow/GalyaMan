# ГАЛЯ МЕН 🍳🐇

**Сезон шапок.** Шуточный 8-битный платформер: Галя в телогрейке и со сковородкой идёт через стальную крепость, где живут очень милые и абсолютно безобидные кролики. Кролики никому не мешали. Но Галя узнала, где они живут.

Вся игра лежит в одном файле `index.html`. Ничего ставить не надо.

## Как поиграть

1. Скачай `index.html` (или весь репозиторий: зелёная кнопка **Code → Download ZIP**).
2. Открой файл в браузере. Всё.

Работает на компе и на телефоне (на телефоне кнопки появляются на экране, удобнее держать горизонтально).

| Действие | Клавиши |
|---|---|
| Бег | стрелки или `A` / `D` |
| Прыжок | `Пробел`, `Z`, `W` или `↑` |
| Сковородка | `X`, `J` или клик мышкой |
| Рывок (неуязвимость, перезарядка 0,8 с) | `C`, `Shift` или `L` |
| Звук | `M` |
| Пауза | `P` |

## Сюжетный режим

После титульного экрана можно выбрать «Сюжет» или «Классику» (прежняя игра без изменений).

В сюжете три этапа, у каждого свой уровень и босс. Кролики здесь дают сдачи.

1. **Деревня Малые Уши** — где Галя родилась и выросла. Босс: Дед Ушан с вилами.
2. **Заноза** — бар с танцовщицами и вышибалами. Босс: Апельсин, катается шаром.
3. **NASRAL 2026** — новогодняя ярмарка ведьмаков. Босс: Король Насрал I, толстый карлик в короне.

- **Враги:** кусачие кролики, метатели морковки, вышибалы в костюмах (три удара), кролики-санты со снежками, ведьмаки с выпадом (два удара). Снаряды можно отбивать сковородкой.
- **Рывок:** проскакивает сквозь врагов и снаряды, один раз можно в воздухе.
- **Боссы:** после серии атак выдыхаются — в этот момент урон двойной.
- **Тихон:** спрятан на каждом этапе, даёт +3 000 000 очков и улетает в Японию.

Код сюжета лежит в `js/04_story.js`; уровни — в `buildStory()`, теми же командами (`floors`, `bl`, `pl`, `mv`, `rb`, `en`, `cs`).

## Что в игре

- **Кролики.** 28 штук, у каждого есть имя и последние слова. Они не атакуют: сидят, дрожат, убегают и предлагают морковку.
- **Сковородка.** От удара у кролика вылезают глаза, потом его рвёт на куски. Остаётся шапка.
- **Комбо.** Три кролика подряд, и Галя ржёт и танцует, пока выжившие смотрят.
- **Галя живая.** Если постоять на месте, она начинает крутить попкой. Иногда смеётся, иногда гавкает.
- **Мороженщик.** Просто проезжает. Никто не знает, кто это.
- **Чемоданы.** Семь штук можно разбить, в каждом своё. Остальные просто повсюду.
- **Босс: Пушистик.** Он добрый и хотел дружить. Урон наносят только его слёзы. Есть кнопка «Пощадить».
- **Титры.** Поимённо.

Опасны только ямы, шипы, разряды и слёзы. Упала в яму — минус сердечко. Зелёные столбики сохраняют прогресс.

## Что где лежит

```
index.html          готовая игра (собирается из всего остального)
js/01_core.js       холст, управление, звук и музыка, шрифт, служебное
js/02_world.js      уровень, кролики, чемоданы, кровь и куски
js/03_game.js       Галя, мороженщик, босс, меню, титры
js/04_story.js      сюжетный режим: этапы, враги, боссы, Тихон
index.tpl.html      шаблон страницы, в который всё вклеивается
art/                исходные листы со спрайтами и фоны
fonts/              пиксельный шрифт Press Start 2P
cut.py              вырезает спрайты из зелёного фона
build_assets.py     собирает спрайты, фоны и шрифт в out/assets.json
build.py            склеивает всё в index.html
```

## Как что-то поменять

После любой правки в `js/` пересобери игру и обнови страницу:

```
python3 build.py
```

Для этого нужен только Python 3, без библиотек.

**Уровень** описан в `js/02_world.js`, в функции `buildLevel1()`. Там короткие команды:

```js
fl(0, 1300);                              // пол от x=0 до x=1300 (разрыв между кусками пола = яма)
bl(990, 346, 70, 40);                     // ящик: x, y верха, ширина, высота
pl(1950, 346, 70);                        // платформа: x, y, ширина (на неё можно запрыгнуть снизу)
mv(4760, 4850, 340, 84, 46);              // платформа, которая ездит между двумя x
rb(580, FY, 'sit', 'привет! ты новенькая?');  // кролик: x, y, тип, реплика
cs(360, FY, 'socks', 0);                  // чемодан: x, y, что внутри, цвет
```

Пара цифр, чтобы уровень был проходимым:

- Экран 800×450, пол на высоте `FY = 386`. Чем меньше `y`, тем выше.
- Галя прыгает вверх примерно на 90 пикселей и вдаль примерно на 130.
- Типы кроликов: `sit` (сидит и дрожит), `give` (протягивает морковку), `run` (убегает).
- Что бывает в чемодане: `socks`, `heart`, `carrots`, `hats`, `matryoshka`, `rabbit`, `letter`.

**Реплики** лежат обычными списками: имена и эпитафии кроликов в начале `js/02_world.js`, крики Пушистика в `js/03_game.js`.

**Новые спрайты.** Положи лист в `art/` (персонажи в ряд на ярко-зелёном фоне `#00FF00`), добавь его в `build_assets.py` и запусти:

```
pip install pillow numpy scipy
python3 build_assets.py
python3 build.py
```
