# ГАЛЯ МЕН 🍳🐇

**Сезон шапок.** Шуточный 8-битный платформер: Галя в телогрейке и со сковородкой идёт через стальную крепость, где живут очень милые и абсолютно безобидные кролики. Кролики никому не мешали. Но Галя узнала, где они живут.

Вся игра лежит в одном файле `index.html`. Ничего ставить не надо.

## Как поиграть

1. Скачай `index.html` (или весь репозиторий: зелёная кнопка **Code → Download ZIP**).
2. Открой файл в браузере. Всё.

Работает на компе и на телефоне (на телефоне кнопки появляются на экране, удобнее держать горизонтально).

| Действие | Клавиши |
|---|---|
| Бег | стрелки или `A` / `D` |
| Прыжок | `Пробел`, `Z`, `W` или `↑` |
| Сковородка | `X`, `J` или клик мышкой |
| Присесть (можно идти вприсядку) | `S` или `↓` |
| Звук | `M` |
| Пауза | `P` |

## Что в игре

- **Кролики.** 28 штук, у каждого есть имя и последние слова. Они не атакуют: сидят, дрожат, убегают и предлагают морковку.
- **Сковородка.** От удара у кролика вылезают глаза, потом его рвёт на куски. Остаётся шапка.
- **Комбо.** Четыре кролика подряд, и Галя ржёт и танцует. Выжившие смотрят.
- **Галя живая.** Если постоять на месте, она либо танцует, либо пьёт водку и закуривает. Иногда смеётся, иногда гавкает.
- **Души.** Иногда из кролика вылетает душа и прощает Галину.
- **Степашки.** У них свой клуб.
- **Мороженщик.** Просто проезжает. Никто не знает, кто это.
- **Тихон.** Приезжает на мотоцикле посреди боя с боссом, кидает в Галю деньги (они лечат) и зовёт в Японию.
- **Чемоданы.** Семь штук можно разбить, в каждом своё. Остальные просто повсюду.
- **Босс: Нудл Дудл.** Святая зайка-ангелочек, зашла к Гале на стрим. Не атакует, урон наносят только её слёзы. Есть кнопка «Пощадить». В награду Галя получает маску кролика.
- **Титры.** Поимённо.
- **Уровни.** После заставки идёт меню уровней. Следующий открывается, когда пройден предыдущий.

Опасны только ямы, шипы, разряды и слёзы. Упала в яму — минус сердечко. Зелёные столбики сохраняют прогресс.

## Что где лежит

```
index.html          готовая игра (собирается из всего остального)
js/01_core.js       холст, управление, звук и музыка, шрифт, служебное
js/02_world.js      уровень, кролики, чемоданы, кровь и куски
js/03_game.js       Галя, мороженщик, Тихон, босс, меню уровней, титры
js/levels/          уровни друзей, по файлу на уровень (_template.js — шаблон)
index.tpl.html      шаблон страницы, в который всё вклеивается
art/                исходные листы со спрайтами и фоны
fonts/              пиксельный шрифт Press Start 2P
cut.py              вырезает спрайты из зелёного фона
build_assets.py     собирает спрайты, фоны и шрифт в out/assets.json
build.py            склеивает всё в index.html
```

## Как что-то поменять

После любой правки в `js/` пересобери игру и обнови страницу:

```
python3 build.py
```

Для этого нужен только Python 3, без библиотек.

### Как сделать свой уровень

Каждый уровень лежит отдельным файлом в `js/levels/`. Трогать чужой код не нужно.

1. Скопируй `js/levels/_template.js` в ту же папку под своим именем без подчёркивания, например `02_ferma.js`. Номер в начале имени задаёт место уровня в меню.
2. Поменяй название и расставь пол, ящики, кроликов и чемоданы. В шаблоне каждая команда подписана.
3. Запусти `python3 build.py` и открой `index.html`.
4. Пришли pull request со своим файлом и пересобранным `index.html`.

Пара цифр, чтобы уровень был проходимым:

- Экран 800×450, пол на высоте `FY = 386`. Чем меньше `y`, тем выше.
- Галя прыгает вверх примерно на 90 пикселей и вдаль примерно на 130.
- Уровень в меню закрыт, пока не пройден предыдущий. Чтобы открыть всё для проверки, набери в консоли браузера `localStorage.galyamen_unlocked = 99` и обнови страницу.

Первый уровень (вся нынешняя игра вместе с боссом) собран в `js/02_world.js`, в функции `buildLevel1()`. В нём можно подсмотреть, как что ставится.

**Реплики** лежат обычными списками: имена и эпитафии кроликов в начале `js/02_world.js`, реплики Нудл Дудл в `js/03_game.js`.

**Новые спрайты.** Положи лист в `art/` (персонажи в ряд на ярко-зелёном фоне `#00FF00`), добавь его в `build_assets.py` и запусти:

```
pip install pillow numpy scipy
python3 build_assets.py
python3 build.py
```
